# issue-06: ref / property named $ref that is not a reference

## Error Signature

- **Keyword**: `ref`
- **Case**: `property named $ref that is not a reference`
- **Normalized got**: `error: bundling error: failed to resolve internal refs for compliance://<draft>/ref/group_<n>: $ref value must be a string`

## Root Cause

Same as issue-02. The processor's `resolveNode` in `cli/processor/local_refs.go` treated every `map[string]any` node with a `$ref` key as a JSON Schema reference, even inside `properties` where `$ref` is just a property name. Fixed by `inPropertyMap` context tracking added in the issue-02 fix.
