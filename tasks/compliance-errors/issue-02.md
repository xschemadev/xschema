# issue-02: ref / property named $ref, containing an actual $ref

## Error Signature

- **Keyword**: `ref`
- **Case**: `property named $ref, containing an actual $ref`
- **Normalized got**: `error: bundling error: failed to resolve internal refs for compliance://<draft>/ref/group_<n>: $ref value must be a string`

## Root Cause

The processor's `resolveNode` in `cli/processor/local_refs.go` treats every `map[string]any` node with a `$ref` key as a JSON Schema reference, even inside `properties` where `$ref` is just a property name.
