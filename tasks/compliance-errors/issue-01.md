# issue-01: ref / root pointer ref

## Error Signature

- **Keyword**: `ref`
- **Case**: `root pointer ref`
- **Normalized got**: `error: bundling error: failed to resolve internal refs for compliance://<draft>/ref/group_<n>: recursive local $ref "#" is not supported`

## Root Cause

The Go processor's `resolveInternalRefs` in `cli/processor/local_refs.go` used a `resolving[ref]` cycle detection map that returned an error whenever a `$ref` pointed back to an already-resolving path — including `$ref: "#"` which always cycles (root references itself). This blocked all recursive root pointer ref schemas from reaching adapters.

## Fix

1. **Go processor** (`cli/processor/local_refs.go`): Changed cycle detection to return the `$ref` object unchanged instead of erroring, keeping it for adapters to handle. Added `$ref: "#"` short-circuit that skips inlining entirely.
2. **TS core IR** (`typescript/packages/core/src/ir/nodes.ts`): Added `RefNode` (kind: `"ref"`) to `SchemaNode` union. Parser resolves `$ref` with cycle detection via `ctx.resolving: Set<string>` — returns `RefNode` when cycle detected.
3. **TS harness template** (`cli/language/langs/typescript/templates.go`): Fixed to define `const {{$s.GroupID}} = {{$s.Schema}}; const schema = {{$s.GroupID}};` so lazy self-references resolve correctly.
4. **Zod adapter**: `case "ref"` → `z.lazy(() => ${_selfRef})`
5. **Effect adapter**: `case "ref"` → `S.suspend(() => ${_selfRef})`
6. **Valibot adapter**: `case "ref"` → `v.lazy(() => ${_selfRef})`
7. **ArkType adapter**: `case "ref"` → `type.unknown.narrow((val, ctx) => ${_selfRef}.allows(val) || ctx.mustBe("valid"))`
8. **Pydantic adapter**: No changes needed — Python parser already handled `$ref` cycles with `RefNode(resolved=None)` emitting `Any`.
