# issue-07: ref / simple URN base URI with $ref via the URN

## Error Signature

- **Keyword**: `ref`
- **Case**: `simple URN base URI with $ref via the URN`
- **Normalized got**: `error: bundling error: failed to resolve internal refs for compliance://<draft>/ref/group_<n>: recursive local $ref "#" is not supported`

## Root Cause

The bundler resolves `$ref: "urn:uuid:deadbeef-1234-ffff-ffff-4321feebdaed"` against the schema's own `$id` (same URN), rewrites it to `$ref: "#"`. Then `resolveInternalRefs` in `cli/processor/local_refs.go` errored on recursive `$ref "#"`. Fixed by issue-01's change to return the `$ref` object unchanged for cycle detection and short-circuit `$ref: "#"`.

## Fix

Already resolved by issue-01's recursive ref handling in `cli/processor/local_refs.go`.
