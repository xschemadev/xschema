## Codebase Patterns

### Shared Cache Architecture (US-001)
- `fetcher.SharedCache` is the single source of truth for all fetched schemas
- Create cache in `generate.go`, pass to `retriever.Options.Cache` and `processor.Options.Cache`
- `metaschema.GetWithCache()` accepts cache parameter for deduplication
- Cache normalizes URIs internally (strips fragments)
- Thread-safe via `sync.RWMutex`

## 2026-01-13 - US-005
- Verified RFC 6901 JSON pointer unescaping order
- Implementation was already correct: URI decode first, then JSON pointer unescape (~1→/, ~0→~)
- Files changed:
  - cli/bundler/bundler_test.go - added edge case tests for RFC 6901 compliance
- **Learnings for future iterations:**
  - RFC 6901 §6: when JSON pointer is in URI fragment, percent-decode first, then apply tilde unescaping
  - For key "literal~1key", encode as `~01` (escape the tilde)
  - For key "uri%2Fslash" (literal percent-2-F), encode as `%252Fslash` (double-encode the percent)
  - The PRD acceptance criteria was wrong - corrected to match actual RFC 6901 spec
