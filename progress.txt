## Codebase Patterns

### Shared Cache Architecture (US-001)
- `fetcher.SharedCache` is the single source of truth for all fetched schemas
- Create cache in `generate.go`, pass to `retriever.Options.Cache` and `processor.Options.Cache`
- `metaschema.GetWithCache()` accepts cache parameter for deduplication
- Cache normalizes URIs internally (strips fragments)
- Thread-safe via `sync.RWMutex`

### Compiled Schema Cache (US-002)
- `validator.CompiledCache` caches compiled schemas by SHA256 content hash
- Hash key includes: schema content + draft hint + sorted metaschema URIs
- Pass cache via `ValidateOptions.Cache` field
- `CacheStats` tracks hits/misses/compiles for testing
- Thread-safe via `sync.RWMutex`

### Parallel Crawl Pattern (US-004)
- Wave-based: collect frontier → parallel fetch → extract refs → repeat
- Use `errgroup.WithContext()` + `g.SetLimit(concurrency)`
- Protect shared state (visited, newFrontier) with `sync.Mutex`
- Pass `Concurrency` via `processor.Options.Concurrency`
- Default: `min(runtime.NumCPU(), 8)`
