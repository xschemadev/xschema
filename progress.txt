### Decisions
- Used CSS variable syntax (`var(--color-fd-card)`, etc.) for SVG `fill`/`stroke` attributes rather than Tailwind utility classes, because SVG inline attributes don't support Tailwind classes — CSS custom properties work directly in SVG attribute values
- Used Tailwind theme classes (`bg-fd-background`, `bg-fd-card`) for HTML `div` elements where Tailwind is applicable
- Kept radial gradient light colors (e.g., `#00E8ED`, `#FFD800`, `#f43f5e`) as hardcoded hex values — these are decorative animation accent colors that don't need to follow the theme system (they're the "glow" effects on animated paths)
- Kept SVG text gradient shimmer animation stop colors (`#666666`, `white`) as-is — these create a visual shimmer effect that works across themes
- Standardized `motion/react` import across all files (animated-paths was the only one using the legacy `framer-motion` import)
- Default `idPrefix` values chosen to be short and descriptive: `"circuit"`, `"flow"`, `"paths"` — avoids collisions when multiple instances render on the same page
