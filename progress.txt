# Ralph Progress Log
Started: Sat Jan 10 01:35:45 AM CET 2026

## Codebase Patterns

- Go code in cli/ directory
- AdapterOutput struct in cli/compliance/types.go receives adapter responses
- TS adapters emit full `import ...` statements (no trailing semicolon)
- TS harness template renders import lines verbatim and appends `;`
- MergeTSImports currently drops some real-world forms (namespace/type-only) until US-013
- Type-only compliance harness uses AdapterOutput.Type
- Compliance can be scoped: `xschema compliance --draft <draft> --keyword <keyword>`
- Avoid full compliance runs unless requested
- `xschema compliance --dev-report` cannot be combined with `--draft`/`--keyword`
- Commit format: `feat(scope): lowercase message`
