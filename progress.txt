## Codebase Patterns

- **Tabs pattern**: Use `<Tabs groupId="pm" items={["bun", "npm", "pnpm", "yarn"]}>` with nested `<Tab value="x">` for package manager selection
- **Import fumadocs components**: `import { Tabs, Tab } from "fumadocs-ui/components/tabs"`
- **Typecheck command**: `bun run types:check` from web/ directory
- **Twoslash virtual files**: For npm packages not published, create virtual type definitions with `// @filename: node_modules/pkg/index.d.ts`. Use `// ---cut---` after setup to hide from output. Place `^?` directly below variable for type popup.
