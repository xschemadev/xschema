# Adapters

Adapters convert JSON Schema into native validation code for your chosen library. Each adapter is a standalone CLI that receives pre-processed schemas from xschema and outputs idiomatic code.

See [What is XSchema](/docs/what-is-xschema) for the full architecture and [Adapter Protocol](/docs/adapters/protocol) for the technical specification.

## About Compliance

Compliance percentages are calculated against the official JSON Schema Test Suite, excluding features that cannot be statically compiled. [Learn more about compliance testing](/docs/compliance).
