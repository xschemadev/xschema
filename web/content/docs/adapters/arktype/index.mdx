The ArkType adapter converts JSON Schema definitions into [ArkType](https://arktype.io) validation schemas with full TypeScript type inference.

## Overview

| | |
|---|---|
| **Package** | `@xschemadev/arktype` |
| **Peer Dependency** | `arktype ^2.0.0` |
| **Compliance** | 100% |

ArkType is a TypeScript-native validation library with a unique syntax that mirrors TypeScript's type syntax. The xschema ArkType adapter generates native ArkType schemas from JSON Schema with:

- **100% compliance** with JSON Schema Test Suite (all supported drafts)
- **Full type inference** - generated schemas include TypeScript types
- **Runtime validation** - validate data with detailed error messages
- **Type-level validation** - errors are surfaced at compile time where possible

## Installation

```bash
# with bun
bun add @xschemadev/arktype arktype

# with npm
npm install @xschemadev/arktype arktype

# with pnpm
pnpm add @xschemadev/arktype arktype
```

## Usage with Framework Mode

The recommended way to use xschema is with the client. First, set up your config:

```jsonc title="user.xschema.jsonc"
{
  "$schema": "https://xschema.dev/schemas/typescript.jsonc",
  "schemas": [
    {
      "id": "Profile",
      "sourceType": "file",
      "source": "./profile.schema.json",
      "adapter": "@xschemadev/arktype"
    }
  ]
}
```

Run the generator:

```bash
bunx xschema generate
```

Then use the generated schemas:

```typescript title="app.ts"
import { createXSchemaClient, XSchemaType } from "@xschemadev/client";
import { type } from "arktype";
import { schemas } from "./.xschema/xschema.gen";

const xschema = createXSchemaClient({
  schemas,
  defaultNamespace: "user",
});

// Get schema - returns an ArkType type
const profileSchema = xschema("Profile");

// Validate by calling directly (ArkType uses direct invocation, not .parse())
const result = profileSchema({
  id: "123",
  email: "alice@example.com",
});

// Check for errors using instanceof
if (result instanceof type.errors) {
  console.error(result.summary);
} else {
  console.log(result); // Fully typed!
}

// Extract type for function signatures
type Profile = XSchemaType<"user:Profile">;
```

## Generated Output

For a JSON Schema like:

```json title="profile.schema.json"
{
  "type": "object",
  "properties": {
    "id": { "type": "string" },
    "email": { "type": "string", "format": "email" },
    "age": { "type": "integer", "minimum": 0 }
  },
  "required": ["id", "email"]
}
```

xschema generates:

```typescript
import { type } from "arktype";

const user_Profile = type({
  id: "string",
  email: "string.email",
  "age?": "integer >= 0",
});
type user_ProfileType = typeof user_Profile.infer;
```

## Supported Features

The ArkType adapter has **100% compliance** across all JSON Schema drafts. All tests pass.

See the [Compliance](/docs/adapters/arktype/compliance) page for the full breakdown by draft.

### Highlights

- All primitive types (`string`, `number`, `integer`, `boolean`, `null`, `array`, `object`)
- String formats (`email`, `uuid`, `uri`, `date-time`, etc.)
- Numeric constraints (`minimum`, `maximum`, `multipleOf`, `exclusiveMinimum`, etc.)
- String constraints (`minLength`, `maxLength`, `pattern`)
- Array constraints (`minItems`, `maxItems`, `uniqueItems`, `contains`, `prefixItems`)
- Object constraints (`required`, `additionalProperties`, `propertyNames`, `unevaluatedProperties`)
- Composition (`allOf`, `anyOf`, `oneOf`, `not`)
- Conditionals (`if`/`then`/`else`)
- References (`$ref`, `$defs`)
