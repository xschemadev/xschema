## What's planned

xschema will support generating **Pydantic** validators from JSON Schema with the same workflow as TypeScript:

```bash
# Planned workflow
pip install xschema xschema-pydantic

# user.xschema.jsonc -> .xschema/xschema_gen.py
xschema generate
```

## Planned features

- **Pydantic v2 support** - Generate native Pydantic models
- **Full type hints** - mypy/pyright compatible type annotations
- **Same compliance** - Validated against JSON Schema Test Suite
- **Same config format** - Reuse `*.xschema.jsonc` files across languages

## Example (preview)

Config file:

```jsonc title="user.xschema.jsonc"
{
  "$schema": "https://xschema.dev/schemas/python.jsonc",
  "schemas": [
    {
      "id": "Profile",
      "sourceType": "file",
      "source": "./profile.schema.json",
      "adapter": "@xschemadev/pydantic"
    }
  ]
}
```

Expected generated output:

```python title=".xschema/xschema_gen.py"
# Generated by xschema - DO NOT EDIT
from pydantic import BaseModel, EmailStr
from typing import Optional

class user_Profile(BaseModel):
    id: str
    name: Optional[str] = None
    email: EmailStr

schemas = {
    "user:Profile": user_Profile,
}
```
