## Quick Overview

xschema works in two steps:

1. **Define** - Write JSON Schema files and xschema config
2. **Generate** - Run `xschema generate` to produce native validators

```bash
# 1. Create a config file (e.g., user.xschema.jsonc)
# 2. Run the generator
bunx xschema generate

# Output: .xschema/xschema.gen.ts with native validators
```

The generated code is:

- **Type-safe** - Full TypeScript types inferred from schemas
- **Native** - Uses your chosen validation library directly (Zod, ArkType, etc.)
- **Compliance-tested** - Validated against the JSON Schema Test Suite
