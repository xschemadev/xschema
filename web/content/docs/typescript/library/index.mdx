## What is Library Mode?

Library mode lets you use xschema adapters as standalone packages, without the CLI or client:

```typescript
import { convert } from "@xschemadev/zod";

const schema = {
  type: "object",
  properties: {
    id: { type: "string" },
    email: { type: "string", format: "email" }
  },
  required: ["id", "email"]
};

const result = convert(schema);
// result.code = 'z.object({ id: z.string(), email: z.string().email() })'
// result.type = 'z.infer<typeof schema>'
```

## When to Use Library Mode

Library mode is ideal when you:

- Already have a build system that handles code generation
- Need to integrate xschema into an existing pipeline
- Want to generate validators dynamically at runtime
- Only need the conversion logic, not the full framework

## Framework Mode (Recommended for Most Projects)

For most projects, we recommend **framework mode** which provides:

- CLI-driven code generation from config files
- Type-safe runtime client for schema lookup
- Automatic output management and stale file cleanup
- Best developer experience with autocomplete and type inference
