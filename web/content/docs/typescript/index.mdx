xschema provides first-class TypeScript support, generating native validators with complete type inference from your JSON Schema definitions.

## Two Ways to Use xschema

### Framework Mode (Recommended)

Use the full xschema framework with the CLI and runtime client:

- CLI generates code from `.xschema.jsonc` config files
- Runtime client provides type-safe schema lookup
- Automatic output management and stale file cleanup
- Best for: new projects, teams wanting full integration

- Import `@xschemadev/zod` (or other adapters) directly
- Call `convert(jsonSchema)` to get validator code
- No CLI or client required
- Best for: existing build systems, custom integrations

## Available Adapters

All adapters are tested against the official JSON Schema Test Suite. Choose based on your project's needs:

| Adapter | Package | Compliance | Best For |
|---------|---------|------------|----------|
| [Zod](/docs/typescript/adapters/zod) | `@xschemadev/zod` | 100% | Most projects - large ecosystem, familiar API |
| [ArkType](/docs/typescript/adapters/arktype) | `@xschemadev/arktype` | 100% | Type-level validation, TS-native syntax |
| [Effect](/docs/typescript/adapters/effect) | `@xschemadev/effect` | 100% | Effect ecosystem integration |
| [Valibot](/docs/typescript/adapters/valibot) | `@xschemadev/valibot` | 98.9% | Smallest bundle size |

## Quick Example

Define schemas in a config file:

```jsonc title="user.xschema.jsonc"
{
  "$schema": "https://xschema.dev/schemas/typescript.jsonc",
  "schemas": [
    {
      "id": "User",
      "adapter": "@xschemadev/zod",
      "sourceType": "json",
      "source": {
        "type": "object",
        "properties": {
          "id": { "type": "string" },
          "email": { "type": "string", "format": "email" }
        },
        "required": ["id", "email"]
      }
    }
  ]
}
```

Generate and use:

```bash
bunx xschema generate
```

```typescript title="app.ts"
import { createXSchemaClient, type XSchemaType } from "@xschemadev/client";
import { schemas } from "./.xschema/xschema.gen.js";

const xschema = createXSchemaClient({ schemas });

// Type-safe schema lookup
const userSchema = xschema("user:User");

// Full type inference
type User = XSchemaType<"user:User">;

function validateUser(data: unknown): User {
  return userSchema.parse(data);
}
```
