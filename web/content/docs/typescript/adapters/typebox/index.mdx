The TypeBox adapter converts JSON Schema definitions into [TypeBox](https://github.com/sinclairzx81/typebox) validation schemas with full TypeScript type inference.

## Overview

TypeBox is a JSON Schema type builder that creates in-memory schemas that can be validated with standard JSON Schema validators. XSchema's TypeBox adapter provides:

- **JSON Schema compatible** - TypeBox schemas are valid JSON Schema
- **Full type inference** - generated schemas include TypeScript types
- **Ajv integration** - validate with the popular Ajv validator
- **Lightweight** - minimal runtime overhead

## Installation

The TypeBox adapter is included with the XSchema CLI. You just need TypeBox and a validator installed in your project:

```bash
npm install @sinclair/typebox ajv
# or
bun add @sinclair/typebox ajv
```

## Usage

Specify `"adapter": "typebox"` in your schema definitions:

```jsonc
{
  "$schema": "https://xschema.dev/schemas/typescript.jsonc",
  "schemas": [
    {
      "id": "User",
      "sourceType": "json",
      "source": {
        "type": "object",
        "properties": {
          "id": { "type": "string", "format": "uuid" },
          "email": { "type": "string", "format": "email" },
          "name": { "type": "string", "minLength": 1 },
          "age": { "type": "integer", "minimum": 0 }
        },
        "required": ["id", "email", "name"]
      },
      "adapter": "typebox"
    }
  ]
}
```

## Generated Output

Running `xschema generate` produces:

```typescript
import { Type, Static } from "@sinclair/typebox";

export const User = Type.Object({
  id: Type.String({ format: "uuid" }),
  email: Type.String({ format: "email" }),
  name: Type.String({ minLength: 1 }),
  age: Type.Optional(Type.Integer({ minimum: 0 })),
});

export type User = Static<typeof User>;
```

## Using Generated Schemas

```typescript
import { User } from "./__generated__/schemas";
import Ajv from "ajv";
import addFormats from "ajv-formats";

const ajv = new Ajv();
addFormats(ajv);

// Validate data
const validate = ajv.compile(User);
if (validate(userData)) {
  console.log(userData); // Typed as User
} else {
  console.error(validate.errors);
}
```

## Supported Features

The TypeBox adapter is currently in early development with limited JSON Schema coverage. See the [Compliance](/docs/typescript/adapters/typebox/compliance) page for detailed coverage by JSON Schema draft.

### Current Support

- Primitive types (`string`, `number`, `integer`, `boolean`, `null`)
- Basic object and array types
- Simple type constraints
- References (`$ref`, `$defs`)

## Limitations

This adapter is in early development. Many JSON Schema features have limited or no support:

- Complex composition (`allOf`, `anyOf`, `oneOf`)
- Conditionals (`if`/`then`/`else`)
- Advanced constraints (`additionalProperties`, `patternProperties`)
- Many validation keywords

See the [Compliance](/docs/typescript/adapters/typebox/compliance) page for the full breakdown. Consider using the Zod or ArkType adapters for more complete JSON Schema support.
