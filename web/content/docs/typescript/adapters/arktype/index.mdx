The ArkType adapter converts JSON Schema definitions into [ArkType](https://arktype.io) validation schemas with full TypeScript type inference.

## Overview

ArkType is a TypeScript validation library with a unique syntax that mirrors TypeScript's type syntax. XSchema's ArkType adapter provides:

- **Excellent compliance** with JSON Schema specifications (99.8% for modern drafts)
- **Full type inference** - generated schemas include TypeScript types
- **Runtime validation** - validate data at runtime with detailed error messages
- **Familiar syntax** - type definitions that look like TypeScript

## Installation

The ArkType adapter is included with the XSchema CLI. You just need ArkType installed in your project:

```bash
npm install arktype
# or
bun add arktype
```

## Usage

Specify `"adapter": "arktype"` in your schema definitions:

```jsonc
{
  "$schema": "https://xschema.dev/schemas/typescript.jsonc",
  "schemas": [
    {
      "id": "User",
      "sourceType": "json",
      "source": {
        "type": "object",
        "properties": {
          "id": { "type": "string", "format": "uuid" },
          "email": { "type": "string", "format": "email" },
          "name": { "type": "string", "minLength": 1 },
          "age": { "type": "integer", "minimum": 0 }
        },
        "required": ["id", "email", "name"]
      },
      "adapter": "arktype"
    }
  ]
}
```

## Generated Output

Running `xschema generate` produces:

```typescript
import { type } from "arktype";

export const User = type({
  id: "string.uuid",
  email: "string.email",
  name: "string >= 1",
  "age?": "integer >= 0",
});

export type User = typeof User.infer;
```

## Using Generated Schemas

```typescript
import { User } from "./__generated__/schemas";

// Validate data
const result = User(userData);
if (result instanceof type.errors) {
  console.error(result.summary);
} else {
  console.log(result); // Fully typed!
}
```

## Supported Features

The ArkType adapter supports the vast majority of JSON Schema keywords. See the [Compliance](/docs/typescript/adapters/arktype/compliance) page for detailed coverage by JSON Schema draft.

### Highlights

- All primitive types (`string`, `number`, `integer`, `boolean`, `null`, `array`, `object`)
- String formats (`email`, `uuid`, `uri`, `date-time`, etc.)
- Numeric constraints (`minimum`, `maximum`, `multipleOf`, `exclusiveMinimum`, etc.)
- String constraints (`minLength`, `maxLength`, `pattern`)
- Array constraints (`minItems`, `maxItems`, `uniqueItems`, `contains`)
- Object constraints (`required`, `additionalProperties`, `propertyNames`)
- Composition (`allOf`, `anyOf`, `oneOf`, `not`)
- Conditionals (`if`/`then`/`else`)
- References (`$ref`, `$defs`)

## Limitations

Some advanced JSON Schema features have partial support:

- `additionalProperties` with `allOf` - properties in applicators may not be examined
- Meta-schema vocabulary validation - custom vocabularies not fully supported

See the [Compliance](/docs/typescript/adapters/arktype/compliance) page for the full breakdown.
