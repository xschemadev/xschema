The Valibot adapter converts JSON Schema definitions into [Valibot](https://valibot.dev) validation schemas with full TypeScript type inference.

## Overview

Valibot is a modular validation library focused on bundle size. XSchema's Valibot adapter provides:

- **Good compliance** with JSON Schema specifications (89%+ for modern drafts)
- **Full type inference** - generated schemas include TypeScript types
- **Tree-shakeable** - only include what you use
- **Minimal bundle size** - modular design keeps bundles small

## Installation

The Valibot adapter is included with the XSchema CLI. You just need Valibot installed in your project:

```bash
npm install valibot
# or
bun add valibot
```

## Usage

Specify `"adapter": "valibot"` in your schema definitions:

```jsonc
{
  "$schema": "https://xschema.dev/schemas/typescript.jsonc",
  "schemas": [
    {
      "id": "User",
      "sourceType": "json",
      "source": {
        "type": "object",
        "properties": {
          "id": { "type": "string", "format": "uuid" },
          "email": { "type": "string", "format": "email" },
          "name": { "type": "string", "minLength": 1 },
          "age": { "type": "integer", "minimum": 0 }
        },
        "required": ["id", "email", "name"]
      },
      "adapter": "valibot"
    }
  ]
}
```

## Generated Output

Running `xschema generate` produces:

```typescript
import * as v from "valibot";

export const User = v.object({
  id: v.pipe(v.string(), v.uuid()),
  email: v.pipe(v.string(), v.email()),
  name: v.pipe(v.string(), v.minLength(1)),
  age: v.optional(v.pipe(v.number(), v.integer(), v.minValue(0))),
});

export type User = v.InferOutput<typeof User>;
```

## Using Generated Schemas

```typescript
import { User } from "./__generated__/schemas";
import * as v from "valibot";

// Validate data
const result = v.safeParse(User, userData);
if (result.success) {
  console.log(result.output); // Fully typed!
} else {
  console.error(result.issues);
}

// Or use parse (throws on error)
const user = v.parse(User, userData);
```

## Supported Features

The Valibot adapter supports most common JSON Schema keywords. See the [Compliance](/docs/typescript/adapters/valibot/compliance) page for detailed coverage by JSON Schema draft.

### Highlights

- All primitive types (`string`, `number`, `integer`, `boolean`, `null`, `array`, `object`)
- String formats (`email`, `uuid`, `uri`, `date-time`, etc.)
- Numeric constraints (`minimum`, `maximum`, `multipleOf`, `exclusiveMinimum`, etc.)
- String constraints (`minLength`, `maxLength`, `pattern`)
- Array constraints (`minItems`, `maxItems`, `uniqueItems`)
- Object constraints (`required`, `additionalProperties`)
- Composition (`allOf`, `anyOf`, `oneOf`, `not`)
- References (`$ref`, `$defs`)

## Limitations

Some JSON Schema features have partial or no support:

- `additionalItems` - tuple validation edge cases
- Complex `additionalProperties` interactions
- Some conditional schema keywords
- `unevaluatedProperties` / `unevaluatedItems`
- Advanced format validation

See the [Compliance](/docs/typescript/adapters/valibot/compliance) page for the full breakdown.

## Bundle Size Advantage

Valibot's modular design means generated schemas only include the validators actually used:

```typescript
// Only these functions are included in your bundle
import { object, string, optional, number, pipe, minLength } from "valibot";
```

This makes Valibot an excellent choice for frontend applications where bundle size matters.
