JSON Schema is the standard for cross-language validation. The tooling around it is a **jungle**.

## The Problem

- **Fragmented ecosystem** - each library implements a different subset of features
- **Hidden limitations** - no documentation of what's actually supported
- **Non-compliance** - most libraries don't follow the JSON Schema spec
- **Complex features fail** - `$ref`, conditionals, `unevaluatedProperties` break silently
- **No trust** - without compliance testing, you can't know if it'll work
- **Poor DX** - you build your own tooling, commands, workflows

You write schemas that should work but break at runtime.

## The Solution

xschema tames the jungle:

1. **Generates native validators** - real Zod, ArkType, Effect, Valibot, Pydantic code
2. **Tests compliance** - every adapter runs against the official JSON Schema Test Suite
3. **[Unified processing](/docs/internals)** - all adapters receive bundled, normalized schemas
4. **Documents everything** - which features work, which don't, and why

Cross-language type safety you can trust.
