## `convert()`

Converts JSON Schema inputs to adapter output by calling the xschema CLI as a subprocess.

```typescript
async function convert(
  schemas: SchemaInput | SchemaInput[],
  options: ConvertOptions,
): Promise<ConvertResult[]>
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `schemas` | `SchemaInput \| SchemaInput[]` | One or more schemas to convert |
| `options` | `ConvertOptions` | Conversion options (adapter is required) |

### Returns

`Promise<ConvertResult[]>` — one result per input schema, in the same order.

### Throws

`ConvertError` when the CLI exits with a non-zero code or its output can't be parsed.

### Example

```typescript
import { convert } from "@xschemadev/runtime";
import { adapter } from "@xschemadev/zod";

const results = await convert(
  {
    namespace: "user",
    id: "Profile",
    schema: {
      type: "object",
      properties: {
        id: { type: "string" },
        email: { type: "string", format: "email" },
      },
      required: ["id", "email"],
    },
  },
  { adapter },
);

console.log(results[0].schema);
// "z.object({ id: z.string(), email: z.string().email() }).passthrough()"
```

## `SchemaInput`

Describes a single schema to convert.

```typescript
interface SchemaInput {
  namespace: string;
  id: string;
  schema: object | boolean;
}
```

| Field | Type | Description |
|-------|------|-------------|
| `namespace` | `string` | Logical grouping for the schema (e.g., `"user"`, `"app"`) |
| `id` | `string` | Unique identifier within the namespace (e.g., `"Profile"`) |
| `schema` | `object \| boolean` | A JSON Schema object, or `true`/`false` for permissive/empty schemas |

The combination of `namespace` and `id` determines the generated variable name (`namespace_id`, e.g., `user_Profile`).

## `ConvertOptions`

Options passed to `convert()`.

```typescript
interface ConvertOptions {
  adapter: XSchemaAdapter;
  cwd?: string;
  executablePath?: string;
  allowFetch?: boolean;
}
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `adapter` | `XSchemaAdapter` | required | The adapter to use — import from an adapter package |
| `cwd` | `string` | `process.cwd()` | Working directory for `$ref` resolution |
| `executablePath` | `string` | `"xschema"` | Path to the xschema CLI binary |
| `allowFetch` | `boolean` | `false` | Enable fetching external `$ref` targets (URLs, files) |

<Callout>
`adapter` accepts an `XSchemaAdapter` object, not a string. Import it from the adapter package:
```typescript
import { adapter } from "@xschemadev/zod";
```
</Callout>

## `ConvertResult`

The output for a single converted schema. Re-exported from `@xschemadev/core`.

```typescript
interface ConvertResult {
  namespace: string;
  id: string;
  varName: string;
  imports: string[];
  schema?: string;
  type?: string;
  validate?: string;
  validationImports?: string[];
}
```

| Field | Type | Description |
|-------|------|-------------|
| `namespace` | `string` | The namespace from the input |
| `id` | `string` | The schema ID from the input |
| `varName` | `string` | Generated variable name (e.g., `user_Profile`) |
| `imports` | `string[]` | Import statements needed by the generated code |
| `schema` | `string?` | Validator code string (e.g., `z.object({...})`) |
| `type` | `string?` | Type expression (e.g., `z.infer<typeof user_Profile>`) |
| `validate` | `string?` | Validation function expression |
| `validationImports` | `string[]?` | Additional imports for the validation function |

`schema` and `type` are optional because an adapter may only generate one or the other. All built-in adapters (Zod, ArkType, Effect, Valibot) generate both.

### Usage with generated code

The fields map directly to what you'd write in a generated file:

```typescript
const result = results[0];

// result.imports    -> ['import { z } from "zod"']
// result.schema     -> 'z.object({ id: z.string(), email: z.string().email() }).passthrough()'
// result.type       -> 'z.infer<typeof user_Profile>'
// result.varName    -> 'user_Profile'

// You could write a file like:
const code = [
  ...result.imports,
  "",
  `export const ${result.varName} = ${result.schema}`,
  `export type ${result.id} = ${result.type}`,
].join("\n");
```

## `XSchemaAdapter`

Identifies an adapter package. Re-exported from `@xschemadev/core`.

```typescript
interface XSchemaAdapter {
  readonly __xschema: true;
  readonly id: string;
  readonly name: string;
}
```

| Field | Type | Description |
|-------|------|-------------|
| `__xschema` | `true` | Brand field — ensures only valid adapter objects are passed |
| `id` | `string` | Package identifier used to resolve the adapter CLI (e.g., `"@xschemadev/zod"`) |
| `name` | `string` | Human-readable adapter name (e.g., `"zod"`) |

You don't construct these manually. Each adapter package exports a pre-built `adapter` constant:

```typescript
import { adapter } from "@xschemadev/zod";      // id: "@xschemadev/zod", name: "zod"
import { adapter } from "@xschemadev/arktype";   // id: "@xschemadev/arktype", name: "arktype"
import { adapter } from "@xschemadev/effect";    // id: "@xschemadev/effect", name: "effect"
import { adapter } from "@xschemadev/valibot";   // id: "@xschemadev/valibot", name: "valibot"
```

## `ConvertError`

Thrown when conversion fails.

```typescript
class ConvertError extends Error {
  readonly stderr: string;

  constructor(message: string, stderr: string);
}
```

| Property | Type | Description |
|----------|------|-------------|
| `message` | `string` | Error description — either parsed from stderr or a fallback |
| `stderr` | `string` | Raw stderr output from the xschema CLI |
| `name` | `string` | Always `"ConvertError"` |

### When it's thrown

- The xschema CLI exits with a non-zero code (invalid schema, missing adapter, external `$ref` without `--allow-fetch`)
- The CLI binary can't be found or spawned
- The CLI's stdout isn't valid JSON

### Example

```typescript
import { convert, ConvertError } from "@xschemadev/runtime";
import { adapter } from "@xschemadev/zod";

try {
  const results = await convert(schema, { adapter });
} catch (error) {
  if (error instanceof ConvertError) {
    console.error("Failed:", error.message);
    console.error("CLI stderr:", error.stderr);
  }
}
```
