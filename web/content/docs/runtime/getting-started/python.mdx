## Prerequisites

- Python 3.10+
- xschema CLI installed and in PATH
- An adapter package installed (e.g., `@xschemadev/zod`)

## Planned Installation

```bash
pip install xschema-runtime
```

## Planned API

The Python runtime will mirror the TypeScript `@xschemadev/runtime` API — an async `convert()` function that takes schema inputs and adapter options, spawns the xschema CLI under the hood, and returns structured results.

### Basic Conversion

```python
from xschema_runtime import convert, ConvertError

# Define your schema input
schema_input = {
    "namespace": "user",
    "id": "Profile",
    "schema": {
        "type": "object",
        "properties": {
            "id": {"type": "string"},
            "name": {"type": "string"},
            "email": {"type": "string", "format": "email"}
        },
        "required": ["id", "email"]
    }
}

# Convert using an adapter
results = await convert(
    schemas=schema_input,
    adapter="@xschemadev/zod"
)

# Each result contains generated code
for result in results:
    print(result.namespace)  # "user"
    print(result.id)         # "Profile"
    print(result.schema)     # generated validator code string
    print(result.type)       # type expression string
    print(result.imports)    # list of import statements
```

### Multiple Schemas

```python
results = await convert(
    schemas=[
        {"namespace": "user", "id": "Profile", "schema": user_schema},
        {"namespace": "app", "id": "Config", "schema": config_schema},
    ],
    adapter="@xschemadev/zod"
)
```

### External $ref Resolution

```python
# Enable fetching for schemas with external $refs
results = await convert(
    schemas=schema_input,
    adapter="@xschemadev/zod",
    allow_fetch=True
)
```

### Error Handling

```python
from xschema_runtime import convert, ConvertError

try:
    results = await convert(schemas=schema_input, adapter="@xschemadev/zod")
except ConvertError as e:
    print(f"Conversion failed: {e}")
    print(f"stderr: {e.stderr}")
```

### Options

| Option | Type | Default | Description |
|---|---|---|---|
| `schemas` | `dict \| list[dict]` | required | Schema input(s) with `namespace`, `id`, and `schema` fields |
| `adapter` | `str` | required | Adapter package ref (e.g., `@xschemadev/zod`) |
| `cwd` | `str \| None` | `None` | Working directory for the xschema CLI |
| `executable_path` | `str \| None` | `None` | Custom path to xschema binary |
| `allow_fetch` | `bool` | `False` | Allow fetching external `$ref` URIs |

## Planned Features

- **Pydantic v2 adapter**: Generate Pydantic models from JSON Schema
- **Full type hints**: Generated models include proper type annotations
- **Async-first**: Async `convert()` matching the TypeScript API
- **Same CLI backend**: Uses the same xschema Go CLI under the hood

## Current Status

Python runtime support is planned. The API will follow the same pattern as the [TypeScript runtime](/docs/runtime/getting-started/typescript), wrapping the xschema CLI to convert JSON Schemas into adapter-specific code.
